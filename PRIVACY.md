# Политика конфиденциальности

Whois Watcher — бесплатный сервис с открытым исходным кодом. Этот документ описывает, какие данные мы собираем и как с ними обращаемся.

## Какие данные мы собираем

### От Telegram
- **Telegram ID** — обязательно, для идентификации
- **Username** — если установлен, для удобства
- **Language code** — для определения языка по умолчанию

Мы **не сохраняем**: имя, фамилию, телефон, фото профиля и другие данные из Telegram.

### От вас при использовании
- **Список доменов**, которые вы добавили на слежение
- **Личные заметки** к доменам (если вы их пишете)
- **Настройки**: язык, часовой пояс, время и дни рассылки
- **Время команд** для расчёта rate limit

### Системные данные
- **Логи команд** (без содержимого личных данных) — для дебага
- **Метрики использования** в агрегированном виде

## Какие данные мы НЕ собираем

- Никаких платёжных данных (сервис бесплатный)
- Никакого содержимого личных диалогов вне команд боту
- Никаких данных из других чатов
- Никакой телеметрии устройства

## Где хранятся данные

В базе данных PostgreSQL на сервере, где развёрнут конкретный экземпляр бота. **Whois Watcher — открытый проект**, кто-либо может развернуть свой экземпляр. Если вы используете публичный экземпляр — данные хранятся на сервере его оператора.

## Сколько хранятся данные

- **Профиль и домены** — пока вы пользуетесь ботом
- **Журнал отправленных уведомлений** — постоянно (для дедупликации)
- **Логи системных событий** — до 30 дней
- **WHOIS-кэш** — общий на всех, не привязан к пользователю

## Как удалить данные

Команда `/delete_me` — удаляет:
- Ваш профиль
- Все ваши домены
- Историю ваших уведомлений
- Ваши настройки

Удаление **необратимо** и не требует обращения к админам.

Общий WHOIS-кэш не содержит привязки к вам и удалению не подлежит — это публичные WHOIS-данные доменов.

## С кем мы делимся данными

**Ни с кем.** Данные не передаются третьим лицам, не продаются, не используются для рекламы.

Исключения:
- Если того требует закон
- При WHOIS-запросах к WHOIS/RDAP-серверам передаётся только сам домен (без вашей привязки)

## Сторонние сервисы

- **Telegram** — мы общаемся с вами через Telegram Bot API. См. [политику Telegram](https://telegram.org/privacy)
- **WHOIS/RDAP-серверы** — отправляем запросы к ним, чтобы получить данные о доменах
- **Sentry** (опционально) — может использоваться оператором для отлова ошибок. Сообщения могут содержать ваш Telegram ID, но не содержимое команд

## Безопасность

- Все секреты (`BOT_TOKEN` и пр.) хранятся в защищённых переменных окружения
- Webhook верифицируется секретным токеном
- Соединение с Telegram — только HTTPS
- БД и Redis недоступны извне

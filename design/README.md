# Design references

Дизайн-референсы (макеты/прототипы от дизайнера). **Это не прод-код** — целевой
внешний вид и поведение для воссоздания в реальной кодовой базе. См. README
внутри каждой версии.

| Раздел | Версия | Дата импорта | Источник | Документация |
|--------|--------|--------------|----------|--------------|
| WebApp (Telegram mini-app) | **v1** | 2026-06-03 | handoff-пакет дизайнера (`whois watcher app.zip`) | [`webapp/v1/README.md`](webapp/v1/README.md) |

## Конвенция

- Каждая итерация дизайна — отдельная версионированная папка: `design/<раздел>/v<N>/`.
- Внутри — `README.md` (handoff-документация: токены, экраны, поведение) + `app/`
  (HTML/React-прототип, дизайн-токены PIN Voice).
- Реализация в боте идёт **отдельным этапом** (ADR 043, см. `handoff/tasks/TASK-0064`):
  переносятся визуальный язык/токены/экраны, а не прототипный код (без unpkg/Babel,
  без «рамки телефона», без сид-данных).

## webapp/v1 — кратко

Telegram WebApp для мониторинга портфеля доменов (RU), дизайн-система PIN Voice
(PT Sans, Material Symbols Rounded, акцент `#e6403a`, CTA `#36a9e1`, тёмная тема).
6 экранов: список доменов, карточка домена (Обзор/WHOIS/SSL/DNS/Email/Поддомены),
дашборд, календарь истечений, лента алертов, «Ещё» (группы/wishlist/импорт/настройки).
Полная спецификация (токены, отступы, радиусы, поведение, модель данных) —
в `webapp/v1/README.md`.

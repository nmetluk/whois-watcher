## Выполненные работы

### Фикс 1: Имена поддоменов в кнопках клавиатуры
**Проблема:** Все кнопки были одинаковыми — «📌 Отслеживать», пользователь не видел какой поддомен за кнопкой.

**Решение:**
- Изменена `subdomains_keyboard()` в `src/bot/keyboards.py`
- Кнопки теперь содержат имя поддомена: `«📌 {subdomain}»`
- Используется `from_punycode()` для отображения IDN

### Фикс 2: Список поддоменов в сообщении
**Проблема:** Сообщение содержало только заголовок с количеством, пользователь не видел список поддоменов.

**Решение:**
- Добавлен ключ локали `commands.subdomains.list_item`
- Хэндлер формирует список поддоменов в формате `• {subdomain}`
- Список добавляется в сообщение после заголовка

### Локали

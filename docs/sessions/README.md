# Session-логи

Per-session отчёты исполнителя. Один файл на сессию:
`SESSION-NNNN-slug.md`, нумерация сквозная, по шаблону
`handoff/templates/session-report.md`.

Это носитель контекста между сессиями (см. `docs/workflow.md`). Каждый
завершённый таск ссылается на свой отчёт через поле `session:`.

Прежний монолитный `SESSION_LOG.md` в корне заморожен (исторический) —
новые записи добавляются только сюда.

**Публичный репозиторий.** Не писать: реальные домены/ID пользователей
бота, runtime-метрики прода, значения из `.env`, секреты.

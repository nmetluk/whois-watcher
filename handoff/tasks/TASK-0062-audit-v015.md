# TASK-0062 — Аудит v0.15 (админ/ops-слой)

> Отдельная сессия после раздела (конвенция CLAUDE.md). Отчёт —
> `handoff/audits/AUDIT-..-v0-15-admin-ops.md`. Образец — AUDIT v0.14.

## Цель

Независимая проверка админ/ops-слоя (ADR 042) перед тегом v0.15.0.

## Объём

- **Безопасность:** бекапы не утекают (локальный том, права); в ops-отчётах и
  audit context — только агрегаты, без `BOT_TOKEN`/контактов/заметок (ADR 019);
  `pg_dump` — аргументы списком (не shell-инъекция); пароль БД не в логах.
- **Надёжность:** ежечасный отчёт не падает при отсутствии/фейле бекапа;
  `audit()` best-effort (не ломает горячий путь); ротация держит ровно 36;
  verify ловит битый дамп; графики headless/пустые данные не роняют.
- **Архитектура:** `audit_log` отдельно от `system_events`; ARQ-конвенция
  (не host-cron); деплой-готовность (pg-client в образе, том смонтирован).
- **Тесты/anti-drift:** моки со `spec`; миграция `audit_log` round-trip на
  Postgres; **полный прогон зелёный** (особое внимание — суит реально гонялся).
- **Перф:** бекап не блокирует loop (subprocess async); графики через
  `to_thread`; cleanup по индексу.

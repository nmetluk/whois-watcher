# TASK-0065 — Офсайт/шифрование бекапов + мелочи (ADR 042)

> Тело самодостаточно. Перед стартом:
> `git checkout main && git pull --rebase origin main`, затем `claim`.
> 🟢 follow-up из аудита v0.15 (`AUDIT-2026-06-09-v0-15-admin-ops.md`). **Не
> блокер тега v0.15.0.** Повышает durability после недавнего инцидента потери
> данных (локальные бекапы не переживут потерю хоста).

## Цель

Дополнить локальные бекапы офсайт-копией (и опц. шифрованием), закрыть мелкие
🟢-ниты аудита.

## Объём

1. **Офсайт-копия бекапа.** После успешного `pg_dump`+verify — выгрузка дампа во
   внешнее хранилище (S3-совместимое / другой хост по SSH/rclone). Конфиг:
   вкл/выкл (`backup_offsite_enabled`), endpoint/bucket/creds (через env/секреты,
   **не** в логах). Ротация офсайта (отдельный keep). Недоступность офсайта ≠
   падение бекапа (локальный всё равно сделан; офсайт-фейл → ok-локально,
   warning + статус).
2. **(опц.) Шифрование** дампа перед выгрузкой (age/gpg/openssl) — т.к. дамп
   содержит PII (registrant-emails, заметки). Ключ — из секрета.
3. **Мелочи аудита:** `backup_keep` — прямой доступ вместо
   `getattr(settings, "backup_keep", 36)`; `cleanup_old_audit_log` — interval
   через bind-параметр вместо f-string.

## Миграции БД

Не требуется.

## Инварианты (защитить тестами)

- Офсайт-фейл не валит локальный бекап (статус: локально ok, офсайт failed).
- Креды/ключ не логируются.
- (если шифрование) расшифровка восстанавливает дамп (round-trip в тесте).

## Definition of Done

- [ ] Per-session отчёт; `handoff.py validate`; PR + зелёный CI
